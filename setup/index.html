Ari's Lightfield Setup

Follow steps in order. Copy commands using the buttons.

0. Login

Download Chrome:
https://www.google.com/chrome/

Login using company email.

Sign into:

  • Google Calendar
  • Slack
  • Notion
  • Linear
  • Rippling
  • GitHub

1. Install Apps

VSCode:
https://code.visualstudio.com/

iTerm2:
https://iterm2.com/

Open iTerm2 for remaining steps.

2. Install Apple Developer Tools

xcode-select --install

Accept popup installer.

3. Install Homebrew

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

PATH Fix (Brew Shell Env)

echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zshrc
eval "$(/opt/homebrew/bin/brew shellenv)"

Verify

brew doctor

4. Install Base Packages

brew install \
neovim \
git \
ripgrep \
fd \
node \
python \
lua \
wget \
tmux \
fzf \
lazygit \
watchman \
postgresql@16 \
redis

5. Install Node Package Managers

brew install pnpm
npm install -g yarn

6. Install Neovim Config

mkdir -p ~/.config/nvim
git clone https://github.com/mastari/nvim-config.git ~/.config/nvim

7. Test Neovim

nvim

Wait for plugins to install.
Quit with: 

:q

8. Configure Git Identity

git config --global user.name "Ari Katz"
git config --global user.email "arikatz.d@gmail.com"
git config --list

9. GitHub SSH Setup

Generate Key

ssh-keygen -t ed25519 -C "arikatz.d@gmail.com"

Start Agent

eval "$(ssh-agent -s)"

Add Key

ssh-add ~/.ssh/id_ed25519

Copy Public Key

pbcopy < ~/.ssh/id_ed25519.pub

Go to:
GitHub → Settings → SSH Keys → New SSH Key

Test

ssh -T git@github.com

10. Install GitHub CLI

brew install gh
gh auth login

11. Install 1Password + CLI

brew install --cask 1password
brew install 1password-cli
op signin

12. Install Docker

brew install --cask docker

Open Docker.app once after installing.

13. Final Update

brew update && brew upgrade

Done

Machine should now have:

  • Homebrew
  • Neovim + config
  • Dev tooling
  • Git identity
  • GitHub SSH auth
  • GitHub CLI
  • 1Password + CLI
  • Docker
  • Watchman + Postgres + Redis
